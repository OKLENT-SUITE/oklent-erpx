# مساعد OKLENT المحلي

المساعد يعمل محلياً داخل خادم التطبيق بصورة افتراضية. لا يتصل بمزود ذكاء اصطناعي أو خدمة خارجية، ولا يحتاج مفتاح API أو إعداداً خارجياً. يعتمد على اختيار المستخدم لنوع تقرير وعلى استعلامات SQL ثابتة ومحددة للقراءة فقط؛ لا ينشئ SQL من نص السؤال ولا ينفذ معاملات أو تغييرات مالية.

## ما يستطيع قراءته

- دليل الاستخدام المضمّن والشرح الثابت لقواعد النظام.
- حالة فاتورة واحدة باستخدام رقمها، مع الإجمالي والمتبقي فقط.
- ملخص الإيرادات والمصروفات، الفواتير والمبالغ غير المحصلة، أرصدة المخزون وقيمته، الأسطول والرحلات والوقود والصيانة، أعمار الذمم، المركز المالي، الإقرار الضريبي، ميزان المراجعة، وقائمة الدخل.
- تقارير الفترة تقبل حتى 366 يوماً. يُحسب الناتج في قاعدة بيانات التطبيق، ولا تُرسل أسماء العملاء أو نصوص الطلبات إلى جهة أخرى.

## التشغيل والتحكم

بعد التحديث وإعادة تشغيل الخدمات من خلال `UPDATE-WINDOWS.cmd`، افتح «مساعد OKLENT» من القائمة. لا يلزم تعديل `.env`. يعمل افتراضياً؛ يمكن تعطيله عند الحاجة بإضافة `AI_LOCAL_ENABLED=false` إلى `.env` ثم إعادة تشغيل الخدمة.

تظل صلاحية تسجيل الدخول والأدوار وحدود عدد الطلبات اليومية والشهرية وسجل التدقيق المنقح فعالة. لا تُخزَّن الأسئلة أو الإجابات. تسجيل التدقيق يحتفظ بنوع الاستعلام واسم المستخدم ووقت التنفيذ والحالة والمدة فقط، دون تكلفة مزود.

## حدود مهمة

هذا مساعد تحليلي محلي بتقارير وأسئلة محددة مسبقاً، وليس نموذجاً لغوياً عاماً؛ لذلك يمكن اختيار التقرير تلقائياً من كلمات السؤال العربية الواضحة، أو تحديده يدوياً؛ إذا كان السؤال ملتبساً لن يخمّن المساعد وسيعرض التقارير المتاحة. الإجابات المناسبة تظهر برسوم SVG وبطاقات مؤشرات مع جدول بيانات بديل. لا ينفذ بحثاً حراً في كل جداول النظام، ولا يقترح قيوداً أو يرحّلها. يمكن توسيع قائمة الأسئلة بإضافة استعلامات معتمدة ثابتة ومراجعة صلاحياتها.
