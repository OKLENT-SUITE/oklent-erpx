## أ) النشر الحقيقي (Docker + نطاق + شهادة)
- [ ] `bash tests/docker-build-check.sh` ينجح على جهاز عليه Docker.
- [ ] `docker compose -f docker-compose.prod.yml up -d --build` يقلع، وكل الخدمات `healthy`.
- [ ] `https://<النطاق>` بشهادة موثوقة (Let's Encrypt/جهة معتمدة) بلا تحذير متصفح؛ `http://` يعيد التوجيه إلى https.
- [ ] https://www.ssllabs.com/ssltest : الدرجة A أو أعلى؛ HSTS ظاهر.
- [ ] `curl -I https://<النطاق>` يعرض CSP وX-Frame-Options وnosniff.
- [ ] تجديد الشهادة الآلي: `certbot renew --dry-run` ينجح.
- [ ] `/legal/privacy.html` و`/legal/terms.html` تفتحان علناً.

## ب) المتصفحات (جدول لكل بند: Chrome / Edge / Firefox / Safari)
- [ ] الدخول، تبديل الشاشات الأربعين، لا أخطاء في Console.
- [ ] RTL: المحاذاة والجداول والأرقام (اللاتينية) والأيقونات صحيحة.
- [ ] الطباعة: فاتورة A4 ثنائية اللغة وتقرير بتر الصفحات.
- [ ] 2FA: مسح QR بتطبيق مصادقة، دخول بالرمز، رمز استرداد.
- [ ] متجر `/shop/<..>`: عرض، سلة، طلب.

## ج) الجوال (Android Chrome، iPhone Safari)
- [ ] تثبيت PWA (إضافة للشاشة الرئيسية) والأيقونة تظهر.
- [ ] كل شاشة قابلة للاستخدام بعرض 360px بلا تمرير أفقي للصفحة.
- [ ] لوحة المفاتيح لا تغطي حقل الإدخال؛ الأرقام تُدخل بلوحة رقمية.
- [ ] وضع الطيران: الصفحة تفتح من الكاش وتُظهر رسالة اتصال مفهومة عند الإرسال.

## د) إمكانية الوصول
- [ ] التباين: Lighthouse/axe بلا مخالفات «serious/critical» في الدخول والفواتير والتقارير.
- [ ] لوحة المفاتيح فقط: كل الأزرار والحقول قابلة للوصول والتركيز ظاهر.
- [ ] قارئ شاشة (NVDA/VoiceOver/TalkBack): الدخول وإنشاء فاتورة بتسميات مفهومة بالعربية.
- [ ] تكبير الخط 200% بلا فقدان محتوى.

## هـ) تعدد العملاء (بيئة حقيقية)
- [ ] أنشئ عميلين؛ سجّل دخولاً بكل منهما في متصفحين؛ لا بيانات مشتركة.
- [ ] أوقف أحدهما: جلساته تُرفض خلال 15 ثانية، والآخر لا يتأثر.
- [ ] نطاق فرعي لعميل يعمل (إن فعّلته) والمتجر `/t/<عميل>/shop/store`.
- [ ] `tenant-backup.sh backup` ثم `restore` على بيئة تجريبية يعيد البيانات.

## و) التشغيل
- [ ] تنبيه uptime يصلك عند إيقاف `api` عمداً.
- [ ] جدولة النسخ الاحتياطي تعمل؛ آخر نسخة أقل من 24 ساعة؛ تمرين استعادة ناجح وقيس RTO.
