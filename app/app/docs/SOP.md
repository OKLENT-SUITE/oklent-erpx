# إجراءات التشغيل القياسية (SOP) — OKLENT BUSINESS

> الهدف: أن يعرف كل مستخدم **ماذا يفعل، ومن يفعله، وماذا تفعل قاعدة البيانات لحمايته**. الأكواد `ERPX-xxxx` هي رسائل PostgreSQL المحاسبية الصارمة.

## 1. الأدوار
| الدور | الصلاحيات |
|---|---|
| viewer | عرض التقارير والقيود |
| cashier | إصدار الفواتير وتسجيل القبض وإضافة العملاء |
| accountant | قيود يدوية، عكس القيود، إقفال الفترات، العقارات والعقود |
| admin | إعادة فتح الفترات، القفل النهائي، إقفال السنة، المستخدمون |

الصلاحيات تُفرض في الـ API **وأيضاً** في قاعدة البيانات: حساب التطبيق `erpx_app` لا يملك INSERT/UPDATE/DELETE على جداول الدفتر؛ يدخلها فقط عبر دوال `SECURITY DEFINER`.

## 2. SOP-01 إنشاء قيد يومية
1. قيود اليومية ← قيد جديد، اختر التاريخ والفرع وأدخل **بياناً واضحاً** (إلزامي ERPX-J005).
2. أدخل سطرين على الأقل، كل سطر مديناً **أو** دائناً (ERPX-J004).
3. استخدم حسابات فرعية فقط (الرئيسية مرفوضة ERPX-A001).
4. بعملة أجنبية: يجب وجود سعر صرف بتاريخ القيد أو قبله (ERPX-C001).
5. رحّل. عند الإنهاء يتحقق PostgreSQL أن **المدين = الدائن** (ERPX-J001).

## 3. SOP-02 تصحيح خطأ
- **لا تعديل ولا حذف** (ERPX-I001). افتح القيد ← «عكس القيد» ← أنشئ القيد الصحيح.
- القيد يُعكس مرة واحدة فقط، والقيد العكسي لا يُعكس (ERPX-J007/J008).
- الفاتورة تُصحَّح بإشعار دائن (سبب إلزامي) لا بالحذف.

## 4. SOP-03 الإقفال الشهري
1. تأكد من تسجيل كل الفواتير والمصروفات وقيود الاستحقاق.
2. راجع ميزان المراجعة (المدين = الدائن) وقائمة المركز المالي (الفرق 0.00) وأعمار الذمم وملخص VAT.
3. نفّذ `verify` من الـ CLI أو شاهد بطاقة «سلامة الدفتر».
4. أقفل الفترة. الإقفال **بالتسلسل** (ERPX-P003). بعده يُرفض أي ترحيل بتاريخها (ERPX-P002).
5. إعادة الفتح: admin فقط وبسبب مكتوب (ERPX-P009) يُسجَّل في `audit_log`، وبشرط فتح الأحدث أولاً (ERPX-P004).
6. بعد تقديم الإقرار الضريبي: **قفل نهائي** للفترة (ERPX-P005).

## 5. SOP-04 إقفال السنة المالية
1. أقفل كل فترات السنة ما عدا الأخيرة. 2. admin ← «إقفال سنة مالية». يُنشأ قيد واحد يصفّر الإيرادات والمصروفات ويرحّل صافي الربح إلى `3300 الأرباح المبقاة` (ERPX-Y001 يمنع التكرار). 3. أقفل الفترة الأخيرة. قائمة الدخل تتجاهل قيد الإقفال فتبقى أرقام السنة ظاهرة.

## 6. SOP-05 دورة الإيجار
1. أضف العقار (تجاري ← ضريبة 15% / سكني ← معفى) ثم الوحدة. 2. أضف المستأجر. 3. أنشئ العقد: يُولَّد جدول الأقساط تلقائياً (شهري/ربع/نصف/سنوي). 4. عند الاستحقاق «إصدار فاتورة»: يُنشأ قيد (مدين 1130 ← دائن 4100 + 2110). 5. «قبض»: مدين بنك/صندوق ← دائن 1130. لا يُسمح بدفع أكثر من المتبقي (ERPX-E009). 6. القسط المفوتَر مجمّد (ERPX-L001). 7. تعارض عقدين لنفس الوحدة في نفس المدة مرفوض بقيد استبعاد (EXCLUDE USING gist).

## 7. SOP-06 الفواتير الإلكترونية
- ضريبية (B2B) تتطلب عميلاً؛ المبسطة (B2C) لا. الرقم الضريبي 15 رقماً يبدأ وينتهي بـ 3.
- ICV يزيد 1 دائماً و PIH = hash الفاتورة السابقة (ERPX-E001/E002). المجاميع تساوي السطور (ERPX-E003/E004).
- ملاحظة: التوقيع الرقمي والإرسال لهيئة الزكاة **غير مفعّلين** — راجع ZATCA.

## 7ب. SOP-09 المشتريات والموردون
1. أضف المورد (الرقم الضريبي 15 رقماً يبدأ وينتهي بـ 3). 2. سجّل فاتورة المورد: التاريخ والاستحقاق والحساب (مصروف / مخزون 1140 / أصل ثابت 12xx) والمبلغ بدون ضريبة ونسبة الضريبة. القيد: مدين الحساب + ضريبة المدخلات 1150 ← دائن الموردون 2120. 3. تكرار رقم فاتورة المورد لنفس المورد مرفوض. 4. السداد من صندوق/بنك (111x/112x) ولا يتجاوز المتبقي (ERPX-B007)، ومحمي من السداد المتزامن بقفل الصف. 5. راجع «الذمم الدائنة» أسبوعياً و«تقارير المشتريات» شهرياً مع ضريبة المدخلات قبل الإقرار.
> فواتير الموردين غير قابلة للتعديل (ERPX-I001). التصحيح يتطلب قيداً عكسياً؛ إشعارات مدين/دائن الموردين غير منفَّذة بعد.

## 7ج. SOP-10 الحجوزات وإسناد الفنيين
1. افتح **الحجوزات** (فلتر الحالة والبحث) وراجع الحجوزات الجديدة (الموقع: منطقة › مدينة › حي، الموعد، الخدمة). 2. اتصل بالعميل للتأكيد ثم اختر **الفني** (يظهر فنيو نفس المدينة أولاً والمشغول معطّل) والتاريخ والوقت والمدة واضغط «إسناد وتأكيد»؛ التعارض الزمني للفني مرفوض. 3. بعد التنفيذ اضغط «إكمال». 4. أدخل **بيانات الفاتورة** (بدون رقم ضريبي: مبسطة؛ مع رقم ضريبي: كل بيانات العنوان إلزامية) ثم «إصدار الفاتورة». 5. حصّل المبلغ من «الفواتير والتحصيل» أو «الحوالات». 6. الإلغاء قبل الفوترة فقط.

## 7د. SOP-11 إدارة الأملاك
1. أضف **الملاك** (فرد/شركة، IBAN صحيح). 2. أضف العقار (تجاري/سكني) وحدّد **ملاكه وحصصهم** (لا تتجاوز 100%). 3. أضف الوحدات الإيجارية: **رقم الوحدة = رقمها المسجّل في شبكة إيجار** و**نوع الوحدة** من القائمة (فيلا، دور، شقة، دوبلكس، استوديو، شقة ملحق، عمارة، برج، شقة وملحق علوي، دور وملحق علوي، فيلا سطح، غرفة سائق، استراحة، مزرعة). 4. أنشئ العقد (يُولَّد الجدول). 5. الإيجار السكني معفى من الضريبة والتجاري 15%.

## 7هـ. SOP-12 المخزون
الاستلام من «أرصدة المخزون» نموذج «تسجيل استلام بضاعة» مع رقم فاتورة المورد. الجرد الدوري من «الجرد والاستلام»: أدخل المعدود فتُسجَّل الفروق كحركة تسوية. لا تعديل مباشر للرصيد.

## 7و. SOP-13 إعدادات القوائم
الإدارة ← **إعدادات القوائم**: لكل قائمة رئيسية وقسم وشاشة مفتاح «تم التفعيل / تم التعطيل». عطّل ما لا تستخدمه ثم «حفظ»؛ التغيير يسري على كل المستخدمين. شاشة إعدادات القوائم و«الإدارة وحسابي» لا تُعطَّلان. التعطيل **إخفاء للواجهة** وليس صلاحية. «العقارات والوحدات» و«الملاك» معطّلتان افتراضياً؛ فعّلهما لإضافة وحدات قبل إنشاء عقود الإيجار.

## 7ز. SOP-14 الموارد البشرية والرواتب والعهد والمصروفات
1. **الموظفون**: إضافة الموظف برقم وظيفي وهوية وطنية وبيانات العقد والراتب والبدلات والاستقطاعات والحساب البنكي. حجب بيانات الرواتب الحساسة عن دور `viewer`. منع حذف الموظف المرتبط بمسيرات أو عهد.
2. **مسيرات الرواتب**: إنشاء مسير شهري يجمع الموظفين النشطين آلياً مع احتساب الراتب الإجمالي والاستقطاعات والصافي. اعتماد المسير ثم ترحيله عبر الدالة المحاسبية `fn_post_payroll` (المدين: حسابات مصروفات الرواتب 5210-5260، الدائن: مستحقات الرواتب 2130 والتأمينات 2140). صرف الرواتب عبر `fn_pay_payroll` يخصم من البنك 1121 ويقفل مستحقات الرواتب.
3. **العهد النقدية**: صرف العهدة عبر `fn_post_custody` (مدين: 1170 عهد موظفين، دائن: 1121 البنك/الصندوق). تسوية العهدة عبر `fn_settle_custody` بالمستندات المؤيدة والفواتير وضريبة المدخلات 1150 ورد النقد المتبقي للصندوق، مع التحقق الصارم من عدم تجاوز رصيد العهدة.
4. **مطالبات المصروفات**: تقديم المطالبة من الموظف، اعتمادها من الإدارة، وترحيلها عبر `fn_post_expense_claim` باحتساب المصروف وضريبة القيمة المضافة 1150 والصرف المباشر أو تعليقها بذمة الموظف.

## 8. SOP-07 النسخ الاحتياطي والاستعادة
```bash
docker compose exec -T db pg_dump -U erpx_owner -Fc erpx > backup-$(date +%F).dump
docker compose exec -T db pg_restore -U erpx_owner -d erpx_restore --clean < backup.dump
```
- جدول يومي + نسخة خارج الجهاز + **اختبار استعادة شهري**. بعد الاستعادة نفّذ `oklentx verify` و`ميزان المراجعة`.

## 9. SOP-08 المستخدمون
- غيّر كلمة مرور admin الابتدائية فوراً. لا تشارك الحسابات. التعطيل بـ `is_active=false` لا بالحذف. كل تغيير في المستخدمين والحسابات والعقود في `audit_log`.
