# الوثائق القانونية — حالة الجاهزية

| الوثيقة | الملف | الحالة |
|---|---|---|
| سياسة الخصوصية | `web/legal/privacy.html` (تُخدَّم على `/legal/privacy.html`) | مسودة منشورة في الواجهة — **تحتاج تعبئة [ ] ومراجعة محامٍ** |
| شروط الاستخدام | `web/legal/terms.html` | كذلك |
| اتفاقية معالجة البيانات | `docs/legal/DPA.md` | مسودة تُوقَّع مع كل عميل |
| اتفاقية مستوى الخدمة | `docs/legal/SLA.md` | مسودة — عدّل الأرقام بعد القياس |
| الترخيص | `LICENSE` + `docs/LICENSING.md` | موحّد؛ **يلزم تأكيد الاسم القانوني** |

## قبل الإطلاق التجاري (لا يمكن إنجازها من داخل الشيفرة)
1. محامٍ سعودي يراجع النصوص الأربعة ويُعبّئ الأقواس، ويتحقق من متطلبات نظام حماية البيانات الشخصية ولوائحه (وتعيين مسؤول حماية بيانات إن لزم، والتسجيل لدى الجهة المختصة إن لزم).
2. نشر الروابط العامة: `https://<نطاقك>/legal/privacy.html` و`/legal/terms.html` (مطلوبة في Google Play).
3. إضافة قائمة المعالجين الفرعيين وربطها من سياسة الخصوصية.
